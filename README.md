# Cyberpunk Rain — Live Wallpaper for Android

Живые обои для Android: пиксель-арт мегаполис в стилистике Blade Runner + процедурный движок ливня, тумана, неона и стекла на WebView-канвасе.

## Что внутри
- `app/src/main/assets/bg.png` — финальный арт 1080x2400 (9:20), пиксель-арт, зафиксирован
- `app/src/main/assets/index.html` — движок обоев v11: 4 слоя дождя (вуаль, занавес, 3 плана капель), rain sheets, приземная брызговая дымка, банки тумана, пар, фликер неона, стекло с каплями по тапу
- `AGENTS.md` — паспорт проекта для ИИ-агентов и будущих меня

## Сборка
Открыть проект в Android Studio, подключить телефон с USB-отладкой, Run.
Активация: долгое нажатие на домашнем экране -> Обои -> Живые обои -> Cyberpunk Rain.
